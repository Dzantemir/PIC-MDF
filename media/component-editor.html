🧩Component

📝Descriptionoptional · shown in the sidebar tooltip
📄Sourcescode compiled into the firmware
One entry per line, relative to the component folder: a folder (scanned recursively), a single file, or a JSON rule such as {"path":"src","pattern":"**/*.c"}. An empty list means this component contributes no sources (a library-only component).
📁Include directoriesheader search paths (-I) — visible to the whole project
One folder per line, relative to the component folder (or absolute). They are passed to the compiler as -I for every source file of the project.
🔗Requirescomponents this one depends on
Determines the link order of prebuilt libraries (a component's libraries are placed before the libraries of the components it requires) and is checked for cycles and for disabled components.
📚Prebuilt librariesready-made static libraries linked into the firmware
One entry per line: a library file or a folder (every library inside is linked). Relative to the component folder.
